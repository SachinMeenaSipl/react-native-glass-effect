Liquid Glass NativeReal glass for React Native, Expo and the web

Live background blur, edge refraction, rim lighting and touch response. One API on Android, iOS and the browser.

Get started
Live web demo
View on GitHub

Android, first-class

GPU blur and an AGSL refraction shader on Android 13+, GPU blur on Android 12, and an automatic snapshot fallback on Android 7–11.

iOS, native by default

Apple's own UIGlassEffect on iOS 26+ and system materials on iOS 15–25. Switch to the library's Metal renderer to match Android.

Expo

Works in Expo dev builds and EAS builds with no config plugin. Expo Go shows a safe fallback instead of crashing.

Web

React, Vite, Next.js (with server-side rendering) and Expo web get glass through CSS backdrop-filter.

One API

Write once. The library picks the best renderer for each device and falls back safely.

Built for real apps

Quality tiers for low-end phones, accessibility settings, theming, diagnostics, and a live tuning panel.

Install ​

sh
npm install react-native-liquid-glass-native
cd ios && pod install
sh
npx expo install react-native-liquid-glass-native
npx expo run:android   # or: npx expo run:ios
sh
npm install react-native-liquid-glass-native react-native-web react-dom

Then rebuild the app. React Native needs the New Architecture (the default since 0.76). On the web, alias react-native to react-native-web in your bundler: see Expo and web.

Quick start ​

Put what the glass should blur inside a <GlassBackdrop>, and render the glass next to it, on top:

tsx
import { StyleSheet, Text, View, ScrollView } from 'react-native';
import { GlassBackdrop, LiquidGlassView } from 'react-native-liquid-glass-native';

export default function Screen() {
  return (
    <View style={{ flex: 1 }}>
      <GlassBackdrop style={StyleSheet.absoluteFill}>
        <ScrollView>{/* photos, lists, gradients… */}</ScrollView>
      </GlassBackdrop>

      <LiquidGlassView
        material="regular"
        style={{ position: 'absolute', top: 60, left: 16, right: 16, padding: 16 }}
      >
        <Text>Hello, glass</Text>
      </LiquidGlassView>
    </View>
  );
}
