Quick start ​

This page puts glass on screen in five minutes. It assumes you've installed the library: if not, start with Installation.

Open full screen ↗

Captured on an Android emulator (shader renderer: blur, refraction and rim light).

Step 1: a background to blur ​

Glass needs something behind it. In the examples on this site, that's Background: a scrolling feed of artwork over a wallpaper (the images live in examples/shared/assets). Use your own content in a real app: photos, a list, a map.

tsx
import { Image, ScrollView, StyleSheet, View } from 'react-native';
import { ART, aurora } from './assets';

/**
 * What the example glass blurs: a vivid wallpaper with a scrolling feed of artwork on top.
 * Every example scene puts this inside a <GlassBackdrop>. In your app, use your own content.
 */
export function Background({ topInset = 120 }: { topInset?: number }) {
  return (
    <View style={StyleSheet.absoluteFill}>
      <Wallpaper />
      <ScrollView contentContainerStyle={[styles.feed, { paddingTop: topInset }]}>
        {ART.map((item) => (
          <Image key={item.title} source={item.image} style={styles.art} />
        ))}
      </ScrollView>
    </View>
  );
}

/** Just the wallpaper, for scenes whose content shouldn't scroll. */
export function Wallpaper() {
  return <Image source={aurora} style={styles.fill} resizeMode="cover" />;
}

const styles = StyleSheet.create({
  // Explicit size: on Android an absoluteFill image without width/height draws at its natural size.
  fill: { position: 'absolute', top: 0, left: 0, width: '100%', height: '100%' },
  feed: { paddingHorizontal: 20, paddingBottom: 260, gap: 22 },
  art: { width: '100%', height: 240, borderRadius: 28 },
});

Step 2: the screen ​

tsx
import { StyleSheet, Text, View } from 'react-native';
import { GlassBackdrop, LiquidGlassButton, LiquidGlassView } from 'react-native-liquid-glass-native';
import { Background } from '../Background';

export default function QuickStart() {
  return (
    <View style={styles.screen}>
      {/* 1. BACKGROUND: everything the glass should blur goes inside the backdrop. */}
      <GlassBackdrop style={StyleSheet.absoluteFill}>
        <Background />
      </GlassBackdrop>

      {/* 2. GLASS: next to the backdrop, on top of it. Never inside it. */}
      <LiquidGlassView material="regular" style={styles.header}>
        <View>
          <Text style={styles.title}>Discover</Text>
          <Text style={styles.subtitle}>New releases this week</Text>
        </View>
        <Text style={styles.count}>8</Text>
      </LiquidGlassView>

      <LiquidGlassButton
        size="large"
        title="Start listening"
        textStyle={styles.ctaText}
        style={styles.cta}
        onPress={() => {}}
      />
    </View>
  );
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#0c1150' },
  header: {
    position: 'absolute',
    top: 48,
    left: 16,
    right: 16,
    padding: 18,
    flexDirection: 'row',
    alignItems: 'center',
    justifyContent: 'space-between',
  },
  title: { color: '#fff', fontSize: 28, fontWeight: '800', letterSpacing: -0.6 },
  subtitle: { color: 'rgba(255,255,255,0.85)', fontSize: 15, marginTop: 2 },
  count: { color: '#fff', fontSize: 34, fontWeight: '200' },
  cta: { position: 'absolute', bottom: 40, alignSelf: 'center' },
  ctaText: { color: '#fff', fontWeight: '700' },
});

What's happening:

  1. <GlassBackdrop> wraps everything the glass should see through. Here it fills the screen with StyleSheet.absoluteFill.
  2. <LiquidGlassView> is rendered next to the backdrop, on top of it. It blurs and bends whatever scrolls underneath.
  3. <LiquidGlassButton> is a glass pill with press feedback.

Step 3: run it ​

sh
npx react-native run-android   # or run-ios
sh
npx expo run:android   # or run:ios
sh
npm run dev

Scroll the feed: the header and button blur it live.

Step 4: check the renderer ​

Add this anywhere to see which renderer your device picked:

tsx
import { useGlassCapabilities } from 'react-native-liquid-glass-native';

const caps = useGlassCapabilities();
console.log(caps.bestRenderer, caps.isNativeAvailable);
// Android 13+: "shader" true · Web: "fallback" false

If isNativeAvailable is false on a phone, the app wasn't rebuilt after installing. See Verify the install.
