Capabilities ​

Ask the device what it can render. Use it to adapt your UI, for example to show a solid header on devices without blur, or to log the renderer in analytics.

Open full screen ↗

Captured on an Android emulator (shader renderer: blur, refraction and rim light).

Example ​

tsx
import { StyleSheet, Text, View } from 'react-native';
import { GlassBackdrop, LiquidGlassCard, useGlassCapabilities } from 'react-native-liquid-glass-native';
import { Background } from '../Background';
import { Eyebrow, text } from '../ui';

export default function CapabilitiesScene() {
  // Re-read automatically when the app returns to the foreground.
  const caps = useGlassCapabilities();

  return (
    <View style={styles.screen}>
      <GlassBackdrop style={StyleSheet.absoluteFill}>
        <Background topInset={40} />
      </GlassBackdrop>

      <View style={styles.stack} pointerEvents="box-none">
        <LiquidGlassCard material="thick" padding={22}>
          <Eyebrow>useGlassCapabilities()</Eyebrow>
          <Text style={styles.renderer}>{caps.bestRenderer}</Text>
          <Text style={text.caption}>
            {caps.platform} {caps.osVersion || ''} · native {caps.isNativeAvailable ? 'available' : 'not available'}
          </Text>

          {Object.entries(caps).map(([key, value]) => (
            <View key={key} style={styles.row}>
              <Text style={text.body}>{key}</Text>
              <Text style={styles.value}>{String(value)}</Text>
            </View>
          ))}
        </LiquidGlassCard>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#0c1150' },
  stack: { flex: 1, justifyContent: 'center', padding: 16 },
  renderer: { color: '#fff', fontSize: 40, fontWeight: '800', letterSpacing: -1 },
  row: {
    flexDirection: 'row',
    justifyContent: 'space-between',
    paddingVertical: 7,
    borderBottomWidth: StyleSheet.hairlineWidth,
    borderBottomColor: 'rgba(255,255,255,0.2)',
  },
  value: { color: '#fff', fontSize: 15, fontWeight: '700' },
});

useGlassCapabilities() ​

A hook that returns the capabilities and re-reads them when the app returns to the foreground, because battery saver and accessibility settings may have changed.

getGlassCapabilities() ​

The same values, synchronously, outside React. It never throws: on any problem it reports the fallback.

ts
import { getGlassCapabilities } from 'react-native-liquid-glass-native';

if (getGlassCapabilities().bestRenderer === 'fallback') {
  // No native glass: Expo Go, web or tests
}

Fields ​

FieldTypeWhat it means
platform'android' | 'ios' | 'web' | 'unknown'Where the app runs
osVersionnumberAndroid API level or iOS major version
bestRenderersee belowThe best renderer this device can use
supportsBlurbooleanThe native renderer can blur. false when native code is missing
supportsRefractionbooleanThe refraction shader is available (Android 13+)
isLowRamDevicebooleanAndroid's low-RAM flag. auto quality uses low
isPowerSaveModebooleanBattery saver is on. auto quality uses low
reduceTransparencybooleanThe system Reduce Transparency setting
reduceMotionbooleanThe system Reduce Motion setting
isNativeAvailablebooleanfalse when native code is missing (Expo Go, web, tests)

Renderers ​

bestRendererWhereWhat it is
shaderAndroid 13+GPU blur + refraction + lighting
blurAndroid 12GPU blur + lighting
compatAndroid 7–11Snapshot + CPU blur
system-glassiOS 26+UIGlassEffect
system-materialiOS 15–25UIVisualEffectView materials
fallbackExpo Go, web, testsPlain view (CSS blur on the web)
