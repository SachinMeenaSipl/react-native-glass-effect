Materials ​

A material is a named look: a set of values for blur, tint, refraction, light and border, with light and dark variants. Every glass starts from one.

Open full screen ↗

Captured on an Android emulator (shader renderer: blur, refraction and rim light).

Example ​

tsx
import { StyleSheet, Text, View } from 'react-native';
import { GlassBackdrop, LiquidGlassView, MATERIALS, type GlassMaterialName } from 'react-native-liquid-glass-native';
import { Background } from '../Background';
import { text } from '../ui';

const NAMES: GlassMaterialName[] = ['thin', 'regular', 'thick', 'clear', 'liquid', 'liquidClear'];

export default function MaterialsScene() {
  return (
    <View style={styles.screen}>
      <GlassBackdrop style={StyleSheet.absoluteFill}>
        <Background topInset={40} />
      </GlassBackdrop>

      <View style={styles.grid} pointerEvents="box-none">
        {NAMES.map((name) => {
          const m = MATERIALS[name];
          return (
            <LiquidGlassView key={name} material={name} style={styles.tile}>
              <Text style={styles.name}>{name}</Text>
              <Text style={text.caption}>
                blur {m.blur} · tint {Math.round(m.tintOpacity.light * 100)}%
              </Text>
            </LiquidGlassView>
          );
        })}
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#0c1150' },
  grid: {
    flex: 1,
    flexDirection: 'row',
    flexWrap: 'wrap',
    alignContent: 'center',
    justifyContent: 'center',
    padding: 12,
    gap: 12,
  },
  tile: { width: '46%', height: 128, padding: 16, justifyContent: 'flex-end' },
  name: { color: '#fff', fontSize: 20, fontWeight: '800', letterSpacing: -0.3 },
});

The values are exported as MATERIALS:

tsx
import { MATERIALS } from 'react-native-liquid-glass-native';

MATERIALS.thick.blur; // 36

Override one value ​

Any prop on a component overrides the material for that component only:

tsx
<LiquidGlassView material="thick" blur={48} tint="#A0C4FF" />

Change a material app-wide ​

Override the preset in the theme. Every component using that material picks it up:

tsx
<GlassThemeProvider
  theme={{
    materials: {
      thick: { blur: 40 },
      regular: { tint: { light: '#FFFFFF', dark: '#101820' } },
    },
  }}
>
  <App />
</GlassThemeProvider>

See Theming.

Light and dark ​

Each material has a light and a dark tint, tint opacity and fallback colour. The library follows the system colour scheme. Force one with colorScheme: 'light' | 'dark' in the theme.

Choosing a material ​

Your content behind the glassText on the glassPick
Busy photo or videoLong textthick
Busy photo or videoA short label or iconthin or clear
Calm colours or gradientsAnythingregular
You want Apple's lookAnythingliquid (or <LiquidGlass>)

thin and clear over busy photos usually fail contrast for body text. See Accessibility.
