Appearance props ​

These props control how a glass surface looks. They work on every glass component and override the material.

Open full screen ↗

Captured on an Android emulator (shader renderer: blur, refraction and rim light).

Example ​

tsx
import { StyleSheet, Text, View } from 'react-native';
import { GlassBackdrop, LiquidGlassView } from 'react-native-liquid-glass-native';
import { Background } from '../Background';

export default function AppearanceScene() {
  return (
    <View style={styles.screen}>
      <GlassBackdrop style={StyleSheet.absoluteFill}>
        <Background />
      </GlassBackdrop>

      <View style={styles.stack} pointerEvents="box-none">
        {/* intensity scales blur, refraction, distortion, light and RGB split together. */}
        <View style={styles.row}>
          <LiquidGlassView intensity={0.3} style={styles.half}>
            <Text style={styles.text}>intensity 0.3</Text>
          </LiquidGlassView>
          <LiquidGlassView intensity={1} style={styles.half}>
            <Text style={styles.text}>intensity 1</Text>
          </LiquidGlassView>
        </View>

        {/* Override single values on top of the material. */}
        <LiquidGlassView material="regular" blur={48} tint="#00C2A8" tintOpacity={0.3} style={styles.full}>
          <Text style={styles.text}>blur 48 · teal tint 30%</Text>
        </LiquidGlassView>

        {/* Light comes from the bottom-left; a stronger rim and border. */}
        <LiquidGlassView illumination={1} lightAngle={135} borderWidth={2} borderOpacity={0.7} style={styles.full}>
          <Text style={styles.text}>light 1 · angle 135° · border 2</Text>
        </LiquidGlassView>

        {/* Square corners and no border. */}
        <LiquidGlassView cornerRadius={0} borderWidth={0} style={styles.full}>
          <Text style={styles.text}>cornerRadius 0 · borderWidth 0</Text>
        </LiquidGlassView>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#0b0b14' },
  stack: { flex: 1, justifyContent: 'center', padding: 16, gap: 14 },
  row: { flexDirection: 'row', gap: 14 },
  half: { flex: 1, height: 90, alignItems: 'center', justifyContent: 'center' },
  full: { height: 72, alignItems: 'center', justifyContent: 'center' },
  text: { color: '#fff', fontSize: 15, fontWeight: '600' },
});

intensity ​

One knob, 0–1, default 1. It multiplies blur, refraction, distortion, illumination and chromatic aberration together. Use it to fade the effect in and out, or to tone down a material without touching each value.

tsx
<LiquidGlassView intensity={0.5} />

blur ​

Blur radius in dp, 0–100 (larger values are clamped to 100). Larger radii cost more GPU time.

On iOS with the system renderer, blur picks the nearest system material on iOS 15–25 and has no effect on iOS 26 (Apple's glass sets its own blur).

tint and tintOpacity ​

A colour laid over the blur, and how strong it is (0–1). Any React Native colour works, including PlatformColor.

tsx
<LiquidGlassView tint="#6D5DFC" tintOpacity={0.18} />
<LiquidGlassView tint={PlatformColor('systemBlue')} /> {/* iOS */}

WARNING

Use tint, not backgroundColor. A background colour is drawn under the blur, so you won't see it.

refraction, distortion, edgeWidth ​

PropRangeWhat it does
refraction0–1How strongly the rim bends the content behind it, like the edge of a thick lens
distortion0–1A slight magnifying-lens effect over the whole surface
edgeWidth0–64 dpHow wide the refracting rim is

Android 13+, and iOS with iosRenderer="shader".

illumination and lightAngle ​

PropRangeWhat it does
illumination0–1Strength of the specular rim highlight
lightAngledegrees, default -60Where the light comes from: -90 top, 0 right, 90 bottom, 180 left

chromaticAberration ​

A rainbow split at the rim, 0–1. Android 13+ with quality="high", and the iOS shader renderer.

cornerRadius ​

Corner radius in dp. If you don't set it, the library uses style.borderRadius, then the theme's cornerRadius (24). It's clamped to half the shortest side, so any large value (such as 999) makes a pill or a circle.

borderWidth and borderOpacity ​

The glass border, 0–8 dp, default 1. It's brighter on the lit side. borderWidth={0} removes it.

WARNING

Use the borderWidth prop, not style.borderWidth. A style border is drawn by React Native on top of the glass border, so you'd get two.

Animating changes ​

When any of these props change, the glass animates to the new values natively over transitionDuration ms (default 180). See Touch and motion.

Match your own UI to the glass ​

resolveMaterial returns the exact values a glass would render with, for example to colour a custom view to match:

tsx
import { resolveMaterial, useGlassTheme } from 'react-native-liquid-glass-native';

const { resolvedScheme, defaultMaterial, materials } = useGlassTheme();
const values = resolveMaterial({
  props: { material: 'thick' },
  colorScheme: resolvedScheme,
  defaultMaterial,
  materialOverrides: materials,
});
// values.tintColor, values.tintOpacity, values.blurRadius, values.fallbackColor…
