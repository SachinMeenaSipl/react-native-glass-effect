GlassThemeProvider ​

Sets app-wide glass defaults once, instead of on every component. It's optional: without it, the library uses the default theme.

Open full screen ↗

Captured on an Android emulator (shader renderer: blur, refraction and rim light).

Import ​

tsx
import { GlassThemeProvider } from 'react-native-liquid-glass-native';

Minimal example ​

A complete screen that uses only React Native and this library. Copy it into App.tsx to try it.

tsx
import { ScrollView, StyleSheet, Text, View } from 'react-native';
import { GlassBackdrop, GlassThemeProvider, LiquidGlassCard } from 'react-native-liquid-glass-native';

const COLORS = ['#ff6b6b', '#feca57', '#48dbfb', '#5f27cd', '#1dd1a1'];

export default function App() {
  return (
    // Defaults for every glass inside. A component prop still wins.
    <GlassThemeProvider theme={{ defaultMaterial: 'thick', cornerRadius: 28 }}>
      <View style={styles.screen}>
        <GlassBackdrop style={StyleSheet.absoluteFill}>
          <ScrollView contentContainerStyle={styles.content}>
            {COLORS.map((color) => (
              <View key={color} style={[styles.block, { backgroundColor: color }]} />
            ))}
          </ScrollView>
        </GlassBackdrop>

        <View style={styles.stack} pointerEvents="box-none">
          <LiquidGlassCard>
            <Text style={styles.text}>From the theme: thick, corners 28</Text>
          </LiquidGlassCard>
          <LiquidGlassCard material="thin">
            <Text style={styles.text}>The prop wins: thin</Text>
          </LiquidGlassCard>
        </View>
      </View>
    </GlassThemeProvider>
  );
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#0b0b14' },
  content: { padding: 16, paddingTop: 40, gap: 16 },
  block: { height: 160, borderRadius: 24 },
  stack: { flex: 1, justifyContent: 'center', padding: 16, gap: 16 },
  text: { color: '#fff', fontSize: 16, fontWeight: '600' },
});

Full example ​

tsx
import { StyleSheet, Text, View } from 'react-native';
import { GlassBackdrop, GlassThemeProvider, LiquidGlassCard, LiquidGlassView } from 'react-native-liquid-glass-native';
import { Background } from '../Background';
import { Eyebrow, text } from '../ui';

export default function ThemeScene() {
  return (
    // App-wide defaults: every glass below uses them unless it passes its own prop.
    <GlassThemeProvider
      theme={{
        defaultMaterial: 'thick',
        cornerRadius: 28,
        materials: {
          thick: { blur: 40, tint: { light: '#E8F0FF', dark: '#0F1A33' } },
        },
      }}
    >
      <View style={styles.screen}>
        <GlassBackdrop style={StyleSheet.absoluteFill}>
          <Background topInset={40} />
        </GlassBackdrop>

        <View style={styles.stack} pointerEvents="box-none">
          <LiquidGlassCard padding={20}>
            <Eyebrow>From the theme · thick, blur 40, corners 28</Eyebrow>
            <Text style={text.title}>3 events today</Text>
            <Text style={text.body}>Standup 10:00 · Lunch 12:30 · Mix review 16:00</Text>
          </LiquidGlassCard>

          {/* A component prop still wins over the theme. */}
          <LiquidGlassCard material="thin" padding={20}>
            <Eyebrow>Prop wins · material="thin"</Eyebrow>
            <Text style={text.title}>8,432 steps</Text>
            <Text style={text.body}>71% of your daily goal</Text>
          </LiquidGlassCard>

          {/* Nested providers: the inner one wins for its subtree. */}
          <GlassThemeProvider theme={{ defaultMaterial: 'clear', cornerRadius: 999 }}>
            <LiquidGlassView style={styles.pill}>
              <Text style={styles.pillText}>Nested theme · clear pill</Text>
            </LiquidGlassView>
          </GlassThemeProvider>
        </View>
      </View>
    </GlassThemeProvider>
  );
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#0c1150' },
  stack: { flex: 1, justifyContent: 'center', padding: 16, gap: 16 },
  pill: { height: 48, alignItems: 'center', justifyContent: 'center', paddingHorizontal: 24, alignSelf: 'center' },
  pillText: { color: '#fff', fontSize: 15, fontWeight: '600' },
});

This is the screen in the preview above. It uses helpers from the repo's examples/shared folder (Background, the ART artwork and drawn icons); replace them with your own content.

Props ​

PropTypeWhat it does
themeGlassThemeOverridesThe values to change. Everything is optional
childrennodeYour app or a part of it

Theme values ​

KeyTypeDefaultWhat it does
defaultMaterialmaterial name'regular'Used when a component has no material prop
defaultQuality'auto' | 'high' | 'medium' | 'low' | 'static''auto'Used when a component has no quality prop
cornerRadiusdp24Used when a component has neither cornerRadius nor style.borderRadius
colorScheme'auto' | 'light' | 'dark''auto'Follow the system, or force light or dark values
iosRenderer'system' | 'shader''system'iOS renderer for every glass without its own iosRenderer, buttons and cards included
materialsper-material partial values{}Overrides merged on top of the built-in presets

Order of precedence ​

Last wins:

  1. The built-in material preset
  2. The theme's materials override for that material
  3. The component's props
  4. intensity scales the strengths, and everything is clamped

Nesting ​

Providers can be nested. The inner one is merged on top of the outer one, for its subtree only. The example's clear pill uses this.

Reading the theme ​

tsx
import { useGlassTheme } from 'react-native-liquid-glass-native';

const { defaultMaterial, resolvedScheme } = useGlassTheme();
// resolvedScheme: the scheme in effect, 'light' or 'dark'
