LiquidGlassButton ​

A pill-shaped glass button with press feedback. It accepts every glass prop, every Pressable prop (onPress, onLongPress, disabled, hitSlop…), and the props below.

Open full screen ↗

Captured on an Android emulator (shader renderer: blur, refraction and rim light).

Example ​

tsx
import { useState } from 'react';
import { StyleSheet, Text, View } from 'react-native';
import { GlassBackdrop, LiquidGlassButton } from 'react-native-liquid-glass-native';
import { Background } from '../Background';

export default function ButtonScene() {
  const [count, setCount] = useState(0);

  return (
    <View style={styles.screen}>
      <GlassBackdrop style={StyleSheet.absoluteFill}>
        <Background />
      </GlassBackdrop>

      <View style={styles.stack} pointerEvents="box-none">
        {/* Three sizes: 36, 48 and 56 dp tall. Pill-shaped by default. */}
        <LiquidGlassButton size="small" title="Small" onPress={() => setCount((n) => n + 1)} />
        <LiquidGlassButton size="medium" title="Medium" onPress={() => setCount((n) => n + 1)} />
        <LiquidGlassButton size="large" title={`Large · pressed ${count}×`} onPress={() => setCount((n) => n + 1)} />

        {/* Custom content instead of a title. */}
        <LiquidGlassButton material="thick" onPress={() => setCount(0)}>
          <Text style={styles.icon}>↺</Text>
          <Text style={styles.label}>Reset</Text>
        </LiquidGlassButton>

        {/* Disabled: dimmed, no press feedback, announced as disabled. */}
        <LiquidGlassButton title="Disabled" disabled />
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#0b0b14' },
  stack: { flex: 1, justifyContent: 'center', alignItems: 'center', gap: 16 },
  icon: { color: '#fff', fontSize: 18 },
  label: { color: '#fff', fontSize: 16, fontWeight: '600' },
});

Props ​

PropTypeDefaultWhat it does
titlestring—The label. Ignored when children is given
childrennode—Custom content, such as an icon and text
size'small' | 'medium' | 'large''medium'Height 36, 48 or 56 dp, with matching padding and font size
styleViewStyle—Outer style: margin, width, position
contentStyleViewStyle—Style of the inner row that holds the content
textStyleTextStyle—Style of the title text
disabledbooleanfalseDims the button, turns off press feedback, announces it as disabled

Plus every LiquidGlassView prop. Two defaults differ:

PropDefault on a button
interactivetrue
cornerRadiushalf the height (a pill)

Label colour ​

The title is near-black (#111111) in light mode and white in dark mode, following the theme's colour scheme. On dark or busy backgrounds, set it yourself:

tsx
<LiquidGlassButton title="New" textStyle={{ color: '#fff' }} onPress={create} />

Press feedback ​

PlatformWhat happens
AndroidNative: a light follows the finger, and the glass squishes and springs back
iOS 26+A small JS scale spring, plus Apple's glass response when the touch lands on the glass itself
iOS 15–25, webA small JS scale spring
Reduce Motion onHighlight only, no movement
disabledNo feedback at all

Accessibility ​

The button announces as a button (accessibilityRole="button"), including its disabled state. Pass accessibilityLabel and accessibilityHint like on any Pressable.
