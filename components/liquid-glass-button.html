LiquidGlassButton ​

A pill-shaped glass button with press feedback. It accepts every glass prop, every Pressable prop (onPress, onLongPress, disabled, hitSlop…), and the props below.

Open full screen ↗

Captured on an Android emulator (shader renderer: blur, refraction and rim light).

Import ​

tsx
import { LiquidGlassButton } from 'react-native-liquid-glass-native';

Minimal example ​

A complete screen that uses only React Native and this library. Copy it into App.tsx to try it.

tsx
import { useState } from 'react';
import { ScrollView, StyleSheet, View } from 'react-native';
import { GlassBackdrop, LiquidGlassButton } from 'react-native-liquid-glass-native';

const COLORS = ['#ff6b6b', '#feca57', '#48dbfb', '#5f27cd', '#1dd1a1'];

export default function App() {
  const [count, setCount] = useState(0);

  return (
    <View style={styles.screen}>
      <GlassBackdrop style={StyleSheet.absoluteFill}>
        <ScrollView contentContainerStyle={styles.content}>
          {COLORS.map((color) => (
            <View key={color} style={[styles.block, { backgroundColor: color }]} />
          ))}
        </ScrollView>
      </GlassBackdrop>

      <View style={styles.buttons} pointerEvents="box-none">
        <LiquidGlassButton
          size="large"
          title={`Pressed ${count}×`}
          textStyle={styles.label}
          onPress={() => setCount((n) => n + 1)}
        />
        <LiquidGlassButton size="small" title="Disabled" textStyle={styles.label} disabled />
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#0b0b14' },
  content: { padding: 16, paddingTop: 40, gap: 16 },
  block: { height: 160, borderRadius: 24 },
  buttons: { position: 'absolute', left: 0, right: 0, bottom: 48, alignItems: 'center', gap: 12 },
  // The default label is dark in light mode; set a colour that suits your background.
  label: { color: '#fff', fontWeight: '700' },
});

Full example ​

tsx
import { useState } from 'react';
import { Image, StyleSheet, Text, View } from 'react-native';
import { GlassBackdrop, LiquidGlassButton } from 'react-native-liquid-glass-native';
import { ART } from '../assets';
import { Wallpaper } from '../Background';
import { PlayIcon } from '../ui';

/** An onboarding screen with every button size, custom content and a disabled state. */
export default function ButtonScene() {
  const [plays, setPlays] = useState(0);

  return (
    <View style={styles.screen}>
      <GlassBackdrop style={StyleSheet.absoluteFill}>
        <Wallpaper />
        <Image source={ART[0].image} style={styles.hero} />
      </GlassBackdrop>

      <View style={styles.content} pointerEvents="box-none">
        <Text style={styles.headline}>Music that sounds{'\n'}like glass.</Text>
        <Text style={styles.subhead}>Millions of songs. No ads. Cancel anytime.</Text>

        {/* Three sizes: 36, 48 and 56 dp tall. Pill-shaped by default. */}
        <LiquidGlassButton size="large" title="Get started" textStyle={styles.strong} style={styles.wide} />
        <LiquidGlassButton size="medium" title="I already have an account" textStyle={styles.label} />

        {/* Custom content instead of a title. */}
        <LiquidGlassButton material="thick" onPress={() => setPlays((n) => n + 1)}>
          <PlayIcon size={16} />
          <Text style={styles.label}>{plays ? `Preview played ${plays}×` : 'Play a preview'}</Text>
        </LiquidGlassButton>

        <View style={styles.row}>
          <LiquidGlassButton size="small" title="Skip" textStyle={styles.label} />
          {/* Disabled: dimmed, no press feedback, announced as disabled. */}
          <LiquidGlassButton size="small" title="Downloading…" textStyle={styles.label} disabled />
        </View>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#0c1150' },
  hero: { position: 'absolute', top: 70, alignSelf: 'center', width: 280, height: 280, borderRadius: 36 },
  content: { flex: 1, justifyContent: 'flex-end', alignItems: 'center', padding: 24, paddingBottom: 44, gap: 14 },
  headline: { color: '#fff', fontSize: 34, fontWeight: '800', letterSpacing: -1, textAlign: 'center' },
  subhead: { color: 'rgba(255,255,255,0.8)', fontSize: 16, textAlign: 'center', marginBottom: 14 },
  wide: { alignSelf: 'stretch' },
  row: { flexDirection: 'row', gap: 12 },
  strong: { color: '#fff', fontWeight: '700' },
  label: { color: '#fff', fontSize: 15, fontWeight: '600' },
});

This is the screen in the preview above. It uses helpers from the repo's examples/shared folder (Background, the ART artwork and drawn icons); replace them with your own content.

Props ​

PropTypeDefaultWhat it does
titlestring—The label. Ignored when children is given
childrennode—Custom content, such as an icon and text
size'small' | 'medium' | 'large''medium'Height 36, 48 or 56 dp, with matching padding and font size
styleViewStyle—Outer style: margin, width, position
contentStyleViewStyle—Style of the inner row that holds the content
textStyleTextStyle—Style of the title text
disabledbooleanfalseDims the button, turns off press feedback, announces it as disabled

Plus every LiquidGlassView prop. Two defaults differ:

PropDefault on a button
interactivetrue
cornerRadiushalf the height (a pill)

Label colour ​

The title is near-black (#111111) in light mode and white in dark mode, following the theme's colour scheme. On dark or busy backgrounds, set it yourself:

tsx
<LiquidGlassButton title="New" textStyle={{ color: '#fff' }} onPress={create} />

Press feedback ​

PlatformWhat happens
AndroidNative: a light follows the finger, and the glass squishes and springs back
iOS 26+A small JS scale spring, plus Apple's glass response when the touch lands on the glass itself
iOS 15–25, webA small JS scale spring
Reduce Motion onHighlight only, no movement
disabledNo feedback at all

Accessibility ​

The button announces as a button (accessibilityRole="button"), including its disabled state. Pass accessibilityLabel and accessibilityHint like on any Pressable.
